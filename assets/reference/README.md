# Small terrain reference

An 8×8 SRTM90m elevation subset near Grand Canyon, sampled through the OpenTopoData public API. Elevations are meters; geographic coordinates are WGS84 latitude/longitude. Adjacent samples are 0.002 degrees apart, not a square metric grid.

SRTM source data: NASA/USGS, public domain. API: https://www.opentopodata.org/datasets/srtm/ . Primary dataset description: https://www.usgs.gov/centers/eros/science/usgs-eros-archive-digital-elevation-shuttle-radar-topography-mission-srtm-1 . Retrieved 2026-10-29. This downsampled crop is a descriptive landform/slope reference, not evidence of centimeter or millimeter geological accuracy.
